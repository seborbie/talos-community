# Talos Community support

Talos Community Edition is self-hosted community software. The project does not promise a service
level, response time, managed deployment, data recovery, or emergency operational support.

Use GitHub issues for reproducible defects and narrowly scoped feature requests. Before filing:

1. remove credentials, tokens, customer data, hostnames, and private logs;
2. confirm the problem against a supported or current revision;
3. include the platform, version/commit, expected behavior, actual behavior, and minimal steps; and
4. state any relevant deployment customizations.

Use [SECURITY.md](SECURITY.md) for vulnerabilities. Questions about a particular hosted or managed
deployment must go to that deployment's operator. The application exposes optional
`PUBLIC_SUPPORT_URL`, `PUBLIC_TERMS_URL`, `PUBLIC_PRIVACY_URL`, and `PUBLIC_SOURCE_URL` settings so
operators can publish their own support, policy, and corresponding-source destinations without
maintaining a source fork.
